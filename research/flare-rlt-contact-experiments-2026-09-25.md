# 从 FLARE 到 RLT：接触后果监督、在线收敛与跨任务迁移

> 2026-09-25 · **探索实验方案，全部未实施**。沿用 [现有研究合同](physical-experience-protocol-2026-09-22.md)和 [loss-first 低成本对照](glow-real2sim2real-experiments.md)；本页只写新增的“FLARE 启发 → 可在 RLT 上实现的接口 → 什么时候算控制收益”。相关 [六篇速记](literature/reading-notes-2026-09-25.md)。

## 0. 问题要拆开

目标不是“预测未来的 loss 能下降”，而是：**在相同交互、专家和计算预算下，学到动作与接触后的实测响应之间的关系，是否帮助 RLT 更快达标、少占用专家，并迁移到未见条件？**

FLARE 本身把未来特征监督放入 action DiT 的模仿学习；当前 RLT 在线阶段是冻结大基座 + 小型 learner。因此先做 **FLARE-inspired** 的小型读出/监督，不称“复现 FLARE”，也不从论文的模仿学习收益推导在线 RL 收敛收益。原 RLT 的特征与 critic 已可能含物理信息；创新要测出增量。

当前 `z_RLT` 若来自 VLA prefix，不能因为加后果 loss 就改称 action-head token。第一轮以**现成 RLT prefix 接口跑通**为优先；若 action-head 特征抽取可复现，再按[既有基准合同](rlt-multitask-benchmark.md)增加等容量 `B0-Head / B1-Head+motion` 比较，分别归因于读取位置和监督来源。

## 1. 先恢复可对照的 RLT

- 先选一个能稳定复位、带接触失败的 RLinf RLT 任务；仓库现有 π0.5 迁移称 `RLT-π0.5-adapted`，本地 residual actor 若接口不同单列 `Local-Residual`。按 [恢复入口](migration-recovery-2026-09-22.md)核准冻结 reference、Stage1 特征和 Stage2 不退化；当前旧 Hammer 实验的专家纠错尚未接通，**不能凭此前日志声称已经减少人为干预**。
- 固定基础模型 checkpoint、参考动作、控制器/归一化、切阶段规则、执行前缀 `K_exec`、命令频率、reward、expert 策略、停止准则与 GPU 时长。VLA 计划 chunk `K_plan` 与实际执行前缀分开；训练标签只和实际执行前缀及相应 `Δt` 对齐。
- 回执最小字段：`obs_t, deployable_history_t, task_id, z_RLT, a_ref, a_proposed, a_accepted[0:K_exec], q_t, q_t+dt, object_t, object_t+dt, event, valid_mask, expert_request, expert_executed, controller_version, source`。训练时使用执行后数据造标签；在线决策不得读取 future truth、sim privileged object state、事后 accepted action 或成功结局。

## 2. 第一优先级：loss-first 的“未来后果”读出

| 模块 | 最小实现与流向 | 容量/时间约束 |
|---|---|---|
| 表示 | `z = fθ(z_RLT, h_t)`；`h_t` 仅含在线可部署的过去 `H` 步、机器人状态与过去执行响应。VLA 与原始 RLT 特征提取器冻结。 | 首轮 `fθ` 为小 MLP；全部方法同 `H`、latent 维度与特征缓存方案。 |
| 训练期 teacher | 对真实执行 `a_exec` 后的 `obs_t+dt` 编码为未来特征 `u_future`；可选 action-aware teacher（FLARE 式），但首轮先固定视觉 teacher。 | teacher 在训练期读取未来；测试时移除 teacher，禁止未来帧进入 actor/critic。 |
| 后果头 | `Dφ(z, a_exec, Δt, task_embed)` 预测 `(Δq_measured, Δeef_object, valid_contact_event, u_future)`，可分支输出；事件标签无把握就 `mask=0`。 | 用执行前缀与实际采样间隔；不把目标位姿、控制命令或不可信视觉估计当真实响应。 |
| 损失 | `L = L_rec + λf L_future + λm L_Huber_motion + λe L_BCE_event`；逐头按有效标签数归一化。 | 在 train/val 选 λ；部署冻结 `fθ` 与 `Dφ`，先只让相同 RLT actor–critic 消费 `z`。 |

**重要梯度边界：** 训练 `Dφ` 时梯度流经 `z` 更新 `fθ`；如果训练完冻结 `fθ,Dφ` 且 actor 的优化目标仍只是 RLT RL loss，后果头只是塑形了输入表示，**不会直接约束 actor 的动作**。要直接选择动作，应进入下面的独立第三阶段，让 D 对候选动作评分；不能把 loss 改进写成“动作已经受物理规律约束”。

**通用未来目标可能忽略接触：** FLARE 式 feature loss 是必要对照；我们的可检验主张是动作条件的、实测末端/物体相对运动和可靠事件标签是否在接触任务上更有帮助。无力/触觉传感器时只能称“接触事件代理/几何后果”，不冒称学会力学定律。

## 3. 零阶段诊断与匹配消融

先从有成功和失败的 20–30 条可对齐轨迹做 pilot（**诊断量，不是显著性样本量**）；按轨迹、物体实例、接触参数切分，不随机拆相邻帧。固定同批数据/teacher / latent 容量 / learner updates 训练下面每组，再在**同样动作条件下**对被留出数据做预测与小规模闭环。

| 组 | 唯一变化 | 排除的问题 |
|---|---|---|
| B0 | 原 RLT 特征与在线 learner | 参考起点；必须先不低于冻结 VLA reference。 |
| B0h | 加同样历史和同容量 `fθ`，只做 RLT 表征重构 | 增加参数/历史本身带来的收益。 |
| Bf | B0h + 未来视觉特征 `L_future` | FLARE 风格未来预测是否足够。 |
| Bm | B0h + 动作条件实测运动 `L_motion` | 是否更贴近执行响应。 |
| Bme | Bm + 有效接触事件 `L_event` | 可靠事件是否提供额外信息。 |
| Bsimple | 同规模只读 `history, proprio, action` 的后果预测器 | 是否 RLT/VLA 特征确实提供增量。 |

扩展读出位置时另加 `B0-Head`（仅更换特征 tap）及 `B1-Head+motion`（相同 head tap + 实测后果）；与 prefix 组共享历史、容量与 RL 配方。必须保存 flow/diffusion 的抽取层、噪声时刻、采样 seed；不能用训练时的未来示范动作作为部署时可得输入。

先用冻结表征的 probe 测接触窗口内的相对位移 MAE、事件 PR-AUC/Brier、不同动作的排序可靠性，并测误差在遮挡/物性变化下的漂移。预测失败即停止扩大在线预算。所有组回到 **同一 Stage2 learner 与 online update 配方**，汇报 RL 成功率随环境步数、真实/仿真墙钟、达到预设目标的时间。不能只挑训练 loss 最低的一组。

## 4. 第二优先级：小型后果模型约束探索（与 loss-first 分开）

**假设：** 读出已经在留出接触条件上校准时，用短时后果过滤候选动作，比单用 Q 或简单缩小 residual 噪声更高效。每次只在 **VLA reference 和 RLT actor 的小幅扰动附近**产生 `M` 个候选；不改变原始 reward。`Dφ(z,a,Δt)` 预测任务相关进展与事件风险（或把预测后果交给同一个 critic 估值），加上多模型预测分歧作为不确定性指标；只有校准范围内的候选可被排序，超出范围回退 reference / 原始安全控制。

示例排序 `score(a)=Q(z,a) + β·pred_progress(a) - γ·pred_contact_failure(a) - η·epistemic_uncertainty(a)`；系数由训练验证条件决定，**留出测试集不调参**。真实后果先前只在已执行动作上观测，因此未执行候选的评分是模型外推；先在仿真可复位完整状态（物体速度、接触、控制器和 RNG）时做同状态分支核验，再用于在线。多模型分歧不能把随机接触的不可约噪声当作可探索的不确定性。原有速度、力矩等明确安全界限仍由控制器处理。

必须比较 `Q-only + M候选`、`Q + 后果 + M候选`、`减小噪声 + M候选`、`等算力 state/history/action dynamics + M候选`；还要报告每步附加推理延迟、GPU 开销和失败回退率。若只靠“减少探索”降低接触失败却令无专家成功率下降，即不构成改进。

## 5. 第三优先级：历史经验与多任务迁移

**记忆先做离线固定库对照：** 每条片段存 `(任务/对象条件, 控制器和本体版本, 当前与过去历史, 执行命令, 实测响应, 有效事件, 最终结局, 来源)`；检索 query 只包含部署当时信息，优先使用已观测过的响应历史而非事后接触真值。对照无记忆、随机检索、语义检索、响应相似检索与同长度普通历史；固定库、top-k、时延和 actor 参数。只有独立留出条件有效，再做经过验证后入库的 online 写入对照，防止数据库增长冒充方法收益。

**两任务 → 第三任务预注册：** 选共享动作语义而物体/接触方式不同的至少两个训练任务，第三个整体留出；先报告每个训练任务原始 RLT 与 Bm/Bme 的 RL 学习曲线，再在留出任务报告 `(a) 不更新直接执行，(b) 固定少量目标域交互微调小 learner，(c) 从头训练小 learner`。物性档位和物体实例也要做留出；不能只在同任务随机初态证明迁移。若 `task_embed` 在新任务上需人工重新设计，单列此成本；不把在验证集上挑选新任务的模型称作 zero-shot。

## 6. 预注册的成功门槛与停机规则

**先定固定目标**（例如在固定无专家评测协议下达到某一成功率门槛，实际数值按 baseline 先验水平预注册），再画含不同训练 seed 的学习曲线并标明未达标截尾。主要指标按顺序是：`达标环境交互数/墙钟`、`累计专家实际控制秒数`（仿真专家不等于人力）、`无专家成功率`；辅助是干预事件数、辅助成功率、恢复率、吞吐量、动作/预测延迟、留出任务适配交互数。**当降低专家时间以牺牲成功率换来时不能宣称成功。**

1. 冻结 reference / B0 不可信、reward / 日志或执行时序混乱 → 停止线上论文比较，先修 baseline。
2. 有效事件标签缺失或与视频/物体状态不对齐 → `λe=0`，先只研究运动后果。
3. `Bsimple` 解释掉全部留出后果预测收益，或 `Bf` 与 `Bm` 无差别 → 收紧“物理经验”主张。
4. 后果预测改善但同预算在线 RL 收敛或专家成本无改善 → 只报告表示结果，不宣称加速训练。
5. 训练任务有效、整体留出任务无效 → 报任务内适配，不宣称跨任务规律或 RSI。

## 可考虑的论文切入点

若 `Bm/Bme > Bf > B0h/B0` 在**对齐容量的预测和在线学习**均成立、且低干预与留出任务结果成立，研究故事才可写成“实测接触后果塑造 RLT 的紧凑控制表示，提高小样本后训练效率与迁移”。如果只有在线候选过滤有效，则论文主题应明确转为“经校准的短时后果约束探索”，补齐同预算模型预测控制、风险门控与恢复方法的近邻比较。两个方向首轮不要绑定为不可分的单一方法。

# Jev、注意力、TTA 与 Astra/harness：分别承担什么

**这些是候选实验，不是已实现能力，也不作为 loss-first 第一轮的必选组件。** 强基模负责提供先验；小型控制 learner、任务记忆和研究 Agent 的更新频率与评价对象应分开。

## 1. Jev：候选选择可以借，快速和物理正确需实测

先沿用仓库对 [EmbodiedJev 的既有分析](../xpace-jev-rlt-ideas.md)，不凭缩写扩展成未经核查的理论。可借鉴的接口是：当前状态有少量已定义候选技能/局部恢复动作，轻量选择器给出选择；环境实际执行并验证。候选来自固定库或固定策略采样，不能由昂贵 oracle 给出最优动作后隐藏其成本。

最小实验：在稳定复现的单类失败上，每次给 K=4 个有界候选；比较固定顺序、随机、原 critic Q、后果预测排序。匹配候选池和总控制/推理预算。若加入高层模型，单列其调用成本与等待；统一报告选中候选成功率、误选代价、p95 延迟和总任务完成时间。

必须承认：有限时域成功概率接近 value；改名“直觉”不是新贡献。预测器要比 Q 多提供可验证的接触响应信息，并在匹配输入/容量后带来决策收益。分支标签需要完整可复原状态；只能取一次真实结果时，不伪造其他候选的反事实标签。此分支排在固定 gate 的 loss 实验后。

## 2. 注意力：先证明失败来自错误依赖，再尝试约束

热图可作诊断，不能仅靠“看起来更集中”认定策略正确。物体外的手爪、工具、支撑面、目标和障碍也可能必要。第一步固定 checkpoint 和输入，按接触阶段比较成功/失败的 patch 权重；同时做目标、干扰物和背景的受控遮挡/替换，检验动作与成功对哪部分敏感。遮挡引入的分布外效应要与随机匹配区域对照。

若明确存在错误依赖，优先训练**有明确含义的小型 patch selector**，而非约束全模型所有层/所有头：

```math
L_{roi}=1-\sum_{j\in R_t}p_\theta(j\mid H_t).
```

R_t 包含当前阶段必要的对象/手爪/接触区域；标注缺失时关闭该项。训练可用仿真分割产生目标，测试主组只用图像预测 selector；真实 mask 作为 oracle 单列。保留同容量无 ROI loss、随机同面积 ROI、固定 crop 和监督 selector 对照；固定其他训练和部署输入。报告闭环成功、干扰变化鲁棒性、遗漏必要区域率与延迟，而不是只展示注意力熵下降。

注意力约束和测试时训练是两件事。若进一步做参数 TTA，仅更新小 adapter/selector，用过去执行回执的自监督误差；基础 VLA、成功判据冻结。固定更新频率/步数、分开 reset-per-episode 与持久更新；先在开发流确定回退规则，最终评测按预注册支持集→独立 query 流执行。低预测损失可能伴随策略漂移，故必须测旧任务保持与成功率。第一轮仅诊断，不在线改基础网络。

## 3. Astra 与 harness：把研究过程变得可追溯

Astra 的直接角色是研究助手：阅读失败片段和统计、提出可反驳假设、生成候选配置与分析脚本。harness 负责固定数据划分、预算、运行、归档、评价与版本接纳。模型名称本身不是科研贡献，也不应未经测量被放进高频接触控制路径。

最小研究循环：固定问题 → 生成一张 [run card](../experiments/rlt-contact-memory/run-card.template.json) → 运行唯一变化 → 独立评价 → 记录接受/否决及理由 → 更新研究记忆。失败实验同样入账。Agent 只能看到训练/开发反馈，最终测试不参与候选选择；训练代码、奖励、评测边界的修改分别版本化。

若发表自动研究部分，需比较固定搜索、无历史 Agent、有经验证历史 Agent，匹配候选空间、GPU、token 与人工预算。若没有这组对照，harness 就作为复现基础设施。只有改进器本身被修改，且新开发问题上改进效率提高，才进一步讨论递归能力；反复调用同一个强模型不充分。

## 4. Skild 启发的课程：待表示稳定后再试

接触操作没有天然对手，不必硬叫 self-play。最小迁移是同一有效扰动集合上比较均匀采样、固定难度分层、按近期学习进展采样。只允许训练采样器调整，最终评测分布固定；不可达/穿模样本不作为难例奖励。采样器探测、筛除和复位成本全部入账，避免通过改变测试难度制造进步。

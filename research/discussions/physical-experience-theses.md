# 研究随想：让实践留下能再次使用的物理经验

**整理者研究立场，2026-09-24。** 根据研究者提供的随想与 loss-first 讨论整理。以下是问题意识和候选假设，不是文献共同结论，不替换仓库既有实验事实。

## 我真正想研究的对象

我关心的不是机器人有没有学过很多动作，而是经历一次有效实践后，下一次能否更快、更稳、更少重复同类错误。预训练提供广泛先验，交互反馈则提供当前身体、物体和接触条件下的知识。人的熟练过程给了我启发，但具体机制仍需要实验检验。

我暂时把“物理直觉”理解为对动作后果的快速判断：夹爪闭合是否真的抓住了物体，继续推进是否有进展，是否该退回重对齐。这些判断可以是隐式表征，不必首先求出质量、摩擦系数或显式力学方程。

## 把几个词分开

| 用词 | 当前可验证的定义 | 第一轮证据 |
| :--- | :--- | :--- |
| 物理后果 | 给定控制接口和时间，实际动作造成的可测变化 | 留出条件的预测与事件校准 |
| 物理约束 | 只在明确适用条件下成立的关系 | 作用于预测量，改善控制且不抹平碰撞/滑移 |
| 经验积累 | 更新后保留可追溯资产，并被后续运行利用 | 同预算保存/清空对照与独立新实例测试 |
| 持续成长 | 新条件学习改善且旧条件能力保留 | 至少多轮更新、旧任务回访、全部成本 |
| 递归改进 | 产生更新的机制自身改变，后续改进效率提高 | 新旧改进器与固定外层对照 |

显式知识库不是成长的唯一载体，参数、技能程序与控制流程也能保留经验。我的兴趣偏向显式记忆，是因为它便于追踪经验来源、做删除/置换对照，并检验什么被复用。

## 我愿意先承担的两个可证伪判断

- **H1：** 在同历史与同容量下，真实动作后果监督提供超出通用未来视觉预测的控制价值。若只提高预测而不提高控制，就收缩为表征分析。
- **H2：** 按接触响应检索，能够帮助新初态或新物理条件。如果随机、视觉近邻或仅近期历史同样好，就不能支持专门的物理响应记忆。

## 模块职责与当下取舍

预训练 VLA 提供初始动作与感知先验；小型 RL learner 学习策略改进；后果模块提供短时可测证据；记忆库保存已发生的交互；harness 组织实验和执行记录。Astra 可以提出失败诊断和修复候选，但真实结果负责验收。Jev 是候选选择路线，必须与本地小头比较。注意力是待诊断变量，热图变化不能代替动作依赖或任务成功证据。

我不把“RL 网络小，所以无法 scale”作为前提。奖励获取、交互成本、稳定性、反馈延迟和数据利用，都可能才是具体瓶颈。视觉缺乏接触信息时，应明确观测不可辨识性；新增触觉/力觉另做传感器与方法因子对照，避免把额外信息优势归因于记忆。

## 收敛原则

每周只推进一个主要机制，留下父版本、假设、控制变量、结果与放弃理由。先通过 RLT baseline 的可信度门槛，再形成后果监督的增量，最后讨论记忆保留。概念可以作为远期方向，近期计划必须落到数据字段、损失、输入接口和独立评测。

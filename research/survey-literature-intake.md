## 单向规则与访问边界

允许：公开原始来源 → RSI；公开原始来源 / RSI 文献卡 → RLT。禁止：RLT 的研究观点、代码设计、实验方案、进度、私聊上下文 → RSI，包括改写成“综述启发”的间接回流。

同一公开 GitHub 仓库的目录划分不是访问控制。本次清理工作树、导航和发布范围，没有重写 Git 历史；既有历史版本仍可访问。需要对项目内容保密时，应另外使用私有仓库并审查历史公开范围。

## 3. RLT Stage 1：paper-aligned base-init smoke 已通过

### 主线口径纠正

第一条 paper-aligned RLT Stage 1 不再以独立 task-SFT checkpoint 作为必要初始化，而是：

```text
通用 π0.5 base
      ↓
目标任务 demonstrations
      ↓
Stage 1 joint training
  ├─ VLA task loss
  └─ RLT reconstruction loss
      ↓
task-adapted VLA + RLT readout
```

本地沿用 RLinf 配置 `rlt_alpha=1.0`；它表示 `rlt_loss + alpha * vla_loss`。RLT reconstruction 的 prefix target 已 detach，所以 RLT reconstruction loss 不反向更新 VLA；VLA 由 `vla_loss` 更新。

### paper-aligned 1-step smoke

- 初始化：通用 π0.5 base；
- 1 optimizer step；
- total loss：3.49118；
- RLT loss：3.06114；
- VLA loss：0.43004；
- grad norm：5.7397；
- checkpoint：667 个 model tensors + 62 个 RLT tensors；
- NaN / Inf：0；
- 退出正常。

### post-SFT 路径

post-SFT warm-start 仍保留为工程兼容性对照。首次 smoke 因 legacy checkpoint key 转换不完整被判无效；loader 修复后已实现 667/667 base tensor 全量匹配并通过 1-step smoke。

这条路径**不作为当前论文主线 Stage 1 初始化方式**。

### 下一步

运行与 paper-aligned smoke 相同初始化/超参数的 **2000-step joint-full**，完成后检查：

- RLT / VLA / total loss 曲线；
- checkpoint 完整性；
- Stage 2 feature loader 能否无缺失加载；
- resolved config 与 run manifest。

## 4. RLT Stage 2：代码语义已进一步对齐，真实 rollout 尚未验收

### 已实现 / 已验证

- 正式 actor action chunk：`C=10`；
- π0.5 reference horizon：`H=50`；
- reference dropout：0.5；
- native env adapter 支持逐子步执行；
- 每个子步记录 reward / done / switch / executed mask / actual executed length；
- early done 后不继续执行剩余子动作；
- terminal observation 与跨 chunk done freeze 有 mock 测试覆盖。

### 需要继续明确的本地差异

当前 actor 使用的是本地 **Local-Residual** 参数化：

```text
executed qpos = reference + residual_scale * tanh(actor output)
```

因此后续结果应标记为：

**RLT-π0.5 adapted / Local-Residual**

而不是逐项等价于原论文 actor parameterization。

### 下一门槛

Stage 1 full 完成以后，直接进行真实 RoboTwin `C=10` Stage 2 smoke，必须看到：

- feature/reference checkpoint 正确加载；
- transition 记录完整；
- replay warmup；
- critic update > 0；
- actor update > 0；
- actor 权重同步至 rollout；
- actor 实际接管；
- 可恢复 checkpoint。

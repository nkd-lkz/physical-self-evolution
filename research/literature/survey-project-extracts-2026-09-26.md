# 从综述区迁回的项目解读

2026-09-26 整理。以下为此前混入文献卡的项目推论与待验证提案，原意保留；不是原论文结论，也没有新增实验结果。仅在 RLT / Physical Token 项目区维护。

## knowin-glow

先实现一个不改奖励的动作回执数据层：记录命令、控制器接收值、实测关节/末端运动、物体响应、时长与观测置信度。对“命令大但实际小”标记**执行不匹配**，保留碰撞、控制饱和、可达性、延迟、跟踪失败等候选原因，不能直接贴成“摩擦过大”或“机器人有痛觉”。

先比较仅本体历史与加入物体响应的后果预测；再比较同控制频率下的常规策略与回执条件策略。试拉/试抬如果加入，必须匹配探测次数与执行时间，分别报告探测带来的额外观测收益和记忆复用收益。

这条线可直接落到 loss-first 的标签和静态记忆条目，不需要先训练生成世界模型。参考[transition 数据合同](../experiments/rlt-contact-memory/implementation.md)。

## simate-autoresearch

先借鉴实验管理，不把云端大模型接到高频控制里。每次候选实验必须提交一张结构化 run card：研究假设、父版本、唯一变化、训练/验证集合、预算、禁止修改项、结果与接纳理由。Astra 可以提出失败假设和配置候选，但环境成功判据、数据划分和预算上限固定。

如单独研究自动科研收益，比较“固定搜索顺序”“Agent 选实验但不保留历史”“Agent 保留经验证研究记忆”三组。各组获得相同候选空间、数据与总算力，报告达到目标所需实验数、无效实验率、人工分钟与独立测试表现。只有确实修改了实验选择器且下一阶段选择效率更高，才进一步研究改进器增强。

## skild-physical-self-play

单臂插入或 Hammer 没有天然对手，不能把普通随机扰动改名 self-play。可以借鉴“能力变化后重新分配练习难度”，先做**受约束的失败状态课程**：

1. 在固定且物理可行的范围生成初始误差、摩擦或负载条件池，每轮只变化一种因素。
2. 固定当前策略，在训练条件池识别接触失败簇；计入全部筛选和试运行成本。
3. 用同一采样总量比较均匀随机、固定分层、按学习进展重分配三种课程。
4. 每轮都在独立、固定的测试分布上评价，禁止通过把测试任务变简单制造增长曲线。

为了先归因到数据分配，第一轮各策略使用同一份已采集的条件池；课程收益成立后才让采集器随新策略更新。这个分支安排在后果表征与静态记忆之后，当前不新增第二个学习对手，也不直接建设大规模足球式训练。

## zeva-ego

这是“后果监督 + 记忆注入”的直接近邻。候选差异应落在 **视觉差分 vs 实测物理响应**、**同实例重试 vs 新实例/条件复用**及相同交互预算下的小型 learner 收益，不能只把模块改名为 Physical Token。见[四条线索对比](../discussions/physical-rsi-sept24.md)和[可执行实验](../experiments/rlt-contact-memory/README.md)。这些是本库提案，不是该论文的实验结论。

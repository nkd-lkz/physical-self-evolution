# Real2sim2real——具身的 scaling 起点：观点拆解与实验边界

> 收录：2026-09-25。类型：用户提供的六页观点文章截图；作者、发布日期与公开原文链接未核实。本文为摘要与研究分析，不转载截图全文，不将其计为论文或已验证系统。

## 文章的核心主张

截图提出：利用强模型辅助场景重建、仿真代码、任务与奖励设计，再在仿真中扩展训练，最后回到真实机器人；同时主张基础动作能力、上层推理与 harness 协同设计。值得保留的问题是：**能否把有限的真实交互转化为可复用的训练环境和经验，而不是只得到一段示范？**

其中关于 Astra 的场景演示、架构优劣和“已经验证”的表述，本轮没有找到对应完整实验协议或原始公开链接。以下严格区分可借鉴的假设与已知方法。

## 五个判断，分别需要什么证据

| 截图中的观点 | 可保留的研究假设 | 不能直接推出什么 |
|---|---|---|
| 少量照片即可重建交互场景 | 强模型可能降低几何建模、资源整理和场景编写成本 | 照片不能唯一确定摩擦、柔顺性、质量或执行器延迟；可操作 Blender 场景不等于动力学已校准 |
| 仿真提供可扩展训练起点 | 在经过检验的任务族中，仿真可提供并行交互与状态标签 | 大量低质量仿真可能放大模型偏差；域随机化不能无条件保证覆盖现实 |
| 强模型自动写任务、奖励与课程 | agent 可以提出环境变体和代码候选 | 自己写奖励再按该奖励自评，可能只是迎合错误指标；需要冻结的外部成功判据 |
| System 1 / System 2 之间要有更好的接口 | 可比较语言、状态摘要、连续紧凑表示的成本与控制效果 | 接口叫 token 并不自动带来物理性、可迁移性或低延迟 |
| AR 更适合、WAM 难以扩展 | 属于待对照的架构假设 | 少量整系统展示不能排除数据、动作接口、算力、harness 与训练配方的混杂 |

行走和接触操作的迁移难点不同，但不能把行走简化成只涉及足地摩擦；执行器、延迟、碰撞、顺应性与感知也会影响迁移。规划器生成轨迹与 model-free RL 也不是同一个概念。

## Real2sim2real 的三个合同

| 合同 | 最小验收问题 | 需要的数据 |
|---|---|---|
| 视觉与几何 | 物体尺度、相机和碰撞几何是否对齐？ | 标定、尺寸、相机观测；不能只靠外观好看 |
| 动力学响应 | 同类命令会产生相近的位移、滑移与接触变化吗？ | 已执行命令、时间戳、关节/末端/物体响应及置信度 |
| 学习与迁移 | 在同预算下，仿真训练是否改善未参与校准的真实任务？ | 独立真机测试、成功/失败规则、训练与人工成本 |

没有真实交互与真实部署测试时，应称为 **sim-to-sim 校准或留出动力学泛化实验**。它可以验证方法机制，但不能写成已经完成 Real2sim2real。

## 不是从 Astra 才开始的方向

以下只用于定位既有研究，不声称完成两篇全文精读，也不改变其历史阅读状态：

- [SAM-RL，RSS 2023](https://www.roboticsproceedings.org/rss19/p040.pdf)：利用可微物理仿真与渲染，由实际观测更新模型并学习策略，包含主动选择观测视角。原总账 P050。
- [One-Shot Real-to-Sim via End-to-End Differentiable Simulation and Rendering](https://arxiv.org/abs/2412.00259)：用一次动作序列中的稀疏视觉/触觉观测联合辨识几何、外观与物理属性。这里的 one-shot 不是一张静态照片。原总账 P052。

因此，可研究的新问题应落在自动化成本、校准预算、任务覆盖或实测迁移增益，而不能以“第一次用仿真回流现实”作为创新声明。

## 对 RLT / Physical Token 的可执行取舍

**先固定已有场景，研究响应，再研究自动造世界。** 用同一机械臂、本体和控制器，在当前可运行的接触任务中改变少数动力学参数，记录回执，检验后果监督是否对留出的条件有增益。初期不把多本体、全屋重建、视频生成与新的动作架构一起引入。

强模型更适合先作为离线研究助手：生成配置候选、检查单位与坐标、整理失败类型、提出受限课程；执行脚本负责运行，独立验证器负责打分，实验清单绑定代码与配置版本。不得把模型的解释直接当力学标签，或让它修改最终测试集来“提高结果”。

记忆可保存“条件—执行—响应—验证”的经验，校准模块可据此调整仿真参数分布，loss-first 可据此监督小型后果读出。它们更新的对象不同，应分开消融。是否压缩成 token 以及是否加快决策，需要在准确率、检索耗时和控制周期上实际测量。

## 建议的下一项实验

[响应校准最小实验](glow-real2sim2real-experiments.md)：在相同几何和控制接口下，比较默认仿真、预设随机化、等数据预算的响应校准。先测留出动作响应，再决定是否值得进行策略训练。只有校准数据上拟合变好而未见条件变差，就停止扩大场景规模。

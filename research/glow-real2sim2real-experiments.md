# GLOW × Real2sim2real：三项最小可证伪实验

> 2026-09-25 · 本库研究提案，全部未执行。来源分别见 [GLOW 专题](../notes/knowin-glow.md)与[Real2sim2real 观点](real2sim2real-scaling-perspective.md)。优先级为 A → B → C；不是一次叠加三个模块，也不替换[当前研究合同](physical-experience-protocol-2026-09-22.md)。

## 共同前置：先让标签可信

选当前已能可靠运行的一个接触任务，固定机器人、基础策略、控制器、动作 chunk 长度、执行前缀、复位和成功判据。先人工检查一小批成功与失败片段，确认命令、仿真/传感器状态与时间戳对齐。

最小样本为 `(obs_t, h_t, a_accepted[t:t+K], dt, y, mask, source)`。`h_t` 截止当前时刻；`y` 在执行结束后计算，包含实测关节变化、物体相对位移以及确有可靠检测手段的接触事件。事件可以暂不训练；无传感器或无法确定时置 mask=0，不能伪造负标签。预测位移与接触事件不等于辨识真实力或摩擦系数。

命令和响应分开：`a_accepted` 指控制器接受的命令，不是事后测得的 Δq。用事后已接受命令训练 D 可作为诊断；若 D 要在线给候选动作排序，必须改为使用决策当时可计算的控制器映射，并验证它与最终执行前缀的一致性。

按轨迹、物体实例和物理配置划分 train/validation/test，同一轨迹窗口不可跨集合；标准化参数只从训练集估计。所有候选方法用相同数据、历史、预算、标签有效掩码与评测条件。

## A · loss-first：实测响应是否改善紧凑表示？

**假设：** 在容量和输入相同的条件下，动作条件的实测后果监督，比重构或通用未来特征监督更有利于留出接触条件下的控制。

`z = fθ(z_RLT, h_t)`；`y_hat = Dφ(z, a_accepted, dt)`。

首轮 f 为小型 MLP，历史先用固定长度拼接；D 为共享 MLP 后接连续量与事件两个头。维度按真实接口确定，不把示例容量当论文定义。VLA 与原始 RLT 特征提取器冻结，更新 f、D 和重构头 R。

`L = L_rec + λm L_motion + λe L_event`

- `L_rec`：R(z) 重构固定特征目标，所有对照使用相同目标。
- `L_motion`：逐维标准化后的 Huber，按有效标签数归一化。Huber 对小残差二次惩罚、大残差线性惩罚；阈值和权重只在验证集选择。
- `L_event`：可靠二值事件的 BCE；单独按有效事件数归一化。首轮没有可靠事件标签时 λe=0。

| 组别 | 相比基线改变什么 | 排除的解释 |
|---|---|---|
| A0 | 同历史、同容量，仅重构 | 是否只是历史/容量增加 |
| A1 | A0 + 实测运动后果 | 运动标签是否有用 |
| A2 | A1 + 有效接触事件 | 接触标签的额外贡献 |
| A3 | A0 + 通用未来特征监督 | 是否任意辅助未来预测都有效 |
| A4 | 本体状态/历史/命令的小预测器；不读 VLA 特征 | VLA/RLT 特征是否真的提供增量 |

A0/A3 的预测质量通过相同训练预算的独立 probe 测量，probe 训练时冻结表示，以免评价过程改变表征。训练后先冻结 f，再分别训练同设置的 RL 头；D 默认只参与训练，不增加每步在线世界模型调用。

**指标：** 留出条件运动误差、事件 Brier/PR-AUC（有标签才报），以及同交互预算下成功率、人工/专家干预、训练曲线和决策延迟。初筛后使用至少三个训练种子，报告逐种子结果与不确定性；不能只报告最好一次。

**停止条件：** 仅训练 loss 下降；A4 已解释全部收益；或表征预测变好但同预算控制无改善。后一种结果只能支持预测表示改进，不能声称机器人更会操作。

## B · 记忆库：检索物理响应比检索语义更有用吗？

先固定 A 的策略/表示，用固定离线库验证读路径。每条记录保存：过去条件、控制器/本体版本、接受命令、实测响应、有效掩码、来源、时间、后续成败及适用范围。保存成功也保存失败；失败条目是避错证据，不直接成为动作示范。

查询只能使用当前和过去可得信息。禁止用当前动作结束后的真实响应作为检索 key，也不能用部署不可得的真实摩擦系数“找同类”。可用过去若干步响应估计的特征；使用隐藏参数检索只能列为 oracle 上界。

固定策略消费记忆的接口与训练预算后，比较无记忆、随机检索、语义检索、响应条件检索；各检索组保持同样库、top-k、上下文长度和编码器容量，另做等长普通历史对照。先将检索结果编码为固定长度摘要向量，不预设离散 token 必然更快。

**指标：** 同类失败重犯率、后续成功率、迁移到留出条件的增益、检索与完整决策 p50/p95 延迟、内存与上下文开销。所有组执行相同安全控制与回退规则。

**第二阶段才允许写入：** 片段通过来源/有效性检查、去重与验证后入库；随机检索组同步获得同一批新经验，另保留禁止写入组。这样才能区分数据增长、检索机制与策略更新。若在线改变表示，必须重建索引或保留编码器版本，不能比较不兼容向量。

**停止条件：** 随机/普通历史已达到相同收益；只在重复测试轨迹上有效；检索延迟抵消控制收益。不要把“数据库变大”直接叫递归自进化。

## C · 响应校准：比更像真的画面更有价值吗？

首轮只选一至两个参数轴，例如物体摩擦与控制延迟，使用固定几何与控制接口。目标环境的隐藏参数不得直接提供给校准算法。通过同预算交互回执，让校准器估计参数或参数分布；不能从一张图唯一恢复所有物性。

| 组别 | 仿真条件 | 校准数据与预算 |
|---|---|---|
| C0 | 默认参数 | 不校准，作为起点 |
| C1 | 预先定义的域随机化 | 固定采样预算 |
| C2 | 回执拟合后的参数分布 | 与比较方法匹配真实/目标域交互数及调参开销 |

先用留出的动作序列比较响应误差与失败类型覆盖，再以相同训练步数比较目标域策略效果。给 C1 同等目标域数据做常规参数选择的额外对照，避免把“多看过目标数据”误当校准算法贡献。为单独检验视觉因素，可后加“外观随机化开/关 × 响应校准开/关”的 2×2 消融。

若从相同状态比较候选动作，复位需要恢复机器人、物体、速度、控制器内部状态与相关随机状态；只重设 qpos 不保证相同接触初态。

**证据命名：** 没有真机数据时，只做 sim-to-sim 隐藏参数测试；有真实校准数据及独立真实部署测试后，才讨论 Real2sim2real。**停止条件：** 只拟合已见轨迹、参数不可辨识导致不稳定，或仿真响应改善却无迁移增益。

## Agent / harness 的具体位置

让强模型离线提出受限配置与实验假设、生成可审查脚本、汇总失败；harness 记录代码 SHA、配置、数据划分、种子、训练预算和结果。验证器与最终测试集固定，模型不得自改打分规则。推理费用、人工修订次数和运行失败都计入自动化成本。

可主张的最低结果是“固定预算下，经过验证的经验复用改善后续任务”。若要讨论递归改进，还需多轮固定协议、固定改进器对照和独立测试，证明提升不只是训练时间、数据或人工投入增加。

# Knowin GLOW：把交互经验编译成监督，而非只积累成功视频

> 2026-09-25 · P132 · 企业技术报告专题阅读；未复现。09-24 已在 RSI 专区收录，本次补入主阅读总账，不重复计算为新发现。优先级 P1：经验接口与标签设计参考。

## 来源与机制

[官方技术页](https://knowinai.com/tech.html)描述：KnowinDream 构造交互经验，KnowinWorld 推演动作后果，Experience Compiler 把轨迹组织为不同监督任务，KnowinAgent 管理记忆与执行反馈；模型采用统一多模态自回归框架。其一教就会展示属于冻结权重的上下文适应，不能直接等同在线策略学习。

报告中的世界状态和机器人已观测历史分开维护；执行回执区分请求与实际响应。最值得本项目借鉴的是**保留经验的时间、对象身份、来源与有效性，再决定它监督什么**。[来源定位：Experience Compiler / Execution Receipt / Hierarchical Memory]

结果口径与限制沿用[已有 RSI 案例核验](https://github.com/nkd-lkz/physical-self-evolution/blob/main/survey-rsi/cases/knowin-glow.md)：企业自评、仿真子集、整系统效果与独立模块贡献需要区分。本次不新增排行榜结论，也不把技术页的示意公式视作完整可复现算法。

## 对 Physical Token 的判断

以下为本库研究分析，不是 GLOW 已证明的结论。

| 问题 | 本项目应如何处理 |
|---|---|
| “物理经验”是什么？ | 有来源与时间对齐的观测—执行命令—实测响应；物理意义首先来自观测与可检验后果，不来自 token 命名 |
| 哪些经验可以监督？ | 仿真步进状态、真实传感器测量、视觉估计、模型想象分别标记；生成后果不能冒充实测真值 |
| 一个片段能做哪些训练？ | 成功动作可用于模仿；成功与失败都可用于后果预测；恢复动作需有后续验证才能成为恢复示范 |
| 是不是已经实现 Physical Token？ | 报告涉及 latent 与动作后果，但没有证明我们拟议的紧凑读出、loss-first 消融或特定迁移假设；也不能反过来宣称这些概念无人提出 |
| 是不是 RSI？ | 上下文适应、经验库增长、权重更新和改进器本身的递归改进分别报告；一次演示与整系统成绩不足以证明最后一项 |

## 最小可借鉴接口：执行回执

建议每个窗口保留以下字段，具体单位、坐标系、频率必须写入数据版本：

| 字段 | 获得方式 | 使用边界 |
|---|---|---|
| `obs_t, history_t` | 当前与过去 RGB、本体状态、已执行命令 | 作为在线输入；不得混入窗口结束后的信息 |
| `a_proposed, a_accepted` | 策略输出与控制器实际接收的命令序列 | 两者分开；控制器接受值仍不是实际运动 |
| `q_t, q_end, dt` | 仿真 step 后状态或同步编码器 | 差值才是实测关节变化；不能拿关节目标代替 |
| `object_response` | 仿真物体状态或视觉/外部跟踪 | 作为标签时标记估计置信度；特权真值不进入部署输入 |
| `contact_event, valid_mask` | 接触查询/传感器及明确规则 | 没有检测到与传感器不可用分开；未知不能写成负样本 |
| `source, controller_version` | 采集管线元数据 | 防止不同控制器、时间尺度和合成来源混为同一经验 |

“命令有位移而实际几乎不动”只能先标作执行不匹配：可能来自接触、延迟、饱和、不可达或控制失败。没有额外观测时，不能直接推断摩擦系数或卡住原因。

## 能立即提出的实验

1. **监督分流**：同一批日志、同样历史与读出容量，对比重构、通用未来特征、实测后果监督；先验证留出条件下预测，再验证控制收益。
2. **记忆有效性**：匹配库大小、检索数量、上下文长度与控制预算，对比随机经验、语义相似经验、接触响应相似经验。先用固定离线库，避免把新增在线数据误认为检索算法收益。
3. **经验固化**：条目记录适用条件、证据与失效条件；经过独立验证后再写入可检索库。在线累积阶段额外比较“有写入”和“禁止写入”，单独报告人工投入。

完整的[三项最小实验与停止条件](../research/glow-real2sim2real-experiments.md)均为待验证提案，不是已完成结果。可复用此前的[回执数据合同与实验模板](https://github.com/nkd-lkz/physical-self-evolution/tree/main/survey-rsi/experiments/rlt-contact-memory)。

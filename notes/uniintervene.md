# UniIntervene：动作后果、停滞判断与记忆恢复

> 2026-09-22 · P130 · **P0：减干预方向的强近邻**。已阅读方法、主实验及相关附录，并核对官方 README；未复现训练或部署。本文只提取与 Physical Token / RLT / 物理经验减少干预相关的内容。

## 1. 工作定位与已验证事实

**UniIntervene: Agentic Intervention for Efficient Real-World Reinforcement Learning**，Haoyuan Deng 等，2026；官方项目页标注 CoRL 2026。它处理的是：已有任务策略持续低效探索时，何时接管、恢复到哪里、怎样生成恢复动作。

- 当前观测、指令和候选动作 → 预测未来视觉 latent；监督来自冻结 V-JEPA2 的后续观测特征。
- 用离线 proxy value 监督双价值头；proxy 结合 TD、进展回归和小权重 CQL，不是无目标、无奖励的物理评分器。
- TVR 聚合价值变化；论文窗口 K=8，依据持续停滞/下降触发，而非每次暂时降分都接管。
- 从按任务组织的历史恢复记忆检索目标，再由目标条件策略生成纠正动作。论文每任务保留 120–240 个目标；恢复输出为 8 步、7 维动作，经 FAST 编码。恢复交互回到 replay，供任务策略学习。

[论文 §3、附录 E–G](https://arxiv.org/html/2606.12372v1)。这是“后果预测—价值判断—恢复控制”的组合；并非调用 Jev，也不是显式力学定律学习。

| 主实验，UR7e 五任务 | HiL-SERL | + UniIntervene |
|---|---:|---:|
| 平均成功率 SR | 81% | 88% |
| 人工干预步数占比 IR | 34.3% | 14.6% |

SR 每任务训练后评估 20 回合；IR 统计三次独立训练运行。成功率增加 **7 个百分点**；人工干预步数占比相对下降约 57%，不能据此等同“总人工工时减少 57%”或“无需盯场”。两任务消融中，去掉记忆目标后，干预 F1 同为 0.882，但 SR 从 95% 降到 85%；该统计范围不同于五任务主实验。[论文 §4、Table 1–2](https://arxiv.org/html/2606.12372v1)

## 2. 对本项目最有价值的三点

以下为本组推论与待验证方向。

**第一，拆开“是否需要帮助”和“帮助能否有效”。** 低进展不说明当前专家一定能恢复；好的触发器也不能补救一个不可用的恢复策略。我们应分别记录触发质量、接管后的条件恢复率及专家时长，避免只报辅助成功率。

**第二，把后果与价值分别评价。** UniIntervene 的未来视觉特征服务于任务价值。我们的增量可以检验：真实执行后果的 grounding，能否提供超出普通视觉未来监督的信息，尤其是在接触条件变化时。预测“滑了多少、跟踪偏差多大”和判断“是否接近目标”需要不同标签；后者仍依赖任务。不能把新增 future head 本身写成创新。

**第三，记忆先保存可验证的恢复证据。** 记录失败上下文、实际恢复动作、实际后果、剩余预算及专家版本。检索得到高价值目标，不代表从当前状态可达；应检验可达性与后续真实效果。固定训练记忆、测试时不写入，才能先隔离经验复用的作用；动态写入是另一个实验。

## 3. 与当前 RLT / Hammer 链路如何衔接

- **base→actor 阶段切换与 expert takeover 是两件事。** UniIntervene 启发后者，不改变原 RL token 的角色，也不能替代尚未验收的 Hammer 恢复执行接口。
- 先沿[当前研究合同](../research/physical-experience-protocol-2026-09-22.md)的问题 A：固定专家与 gate，检查后果监督的表示收益；之后独立研究问题 B：固定策略与专家，比较普通停滞门控、未来视觉门控与实测后果门控。
- K=8 是其采样/决策节奏下的配置，不能直接搬到 H50/C50 名义 waypoint 链路。窗口须换成明确实际时长、可用决策次数和剩余预算，避免等窗口填满时任务已结束。
- 专家接管后，只能监督实际执行的专家动作后果。未执行的学生候选动作不能直接贴上失败标签；反事实优势需要可靠分支实验或另行说明不可识别部分。

## 4. 实现与证据边界

[官方 README](https://github.com/Denghaoyuan123/UniIntervene)明确当前发布的是 NTTG → proxy value → 标注/挖掘 → VQ1 → memory → VQ2 的**离线训练流程**；真机部署与 HIL-SERL 集成不在此包内，轨迹、权重及记忆库也未随包提供。示例配置不等于论文全部任务配置，不能据其直接宣称可接入 RLinf。

还需注意：离线挖掘会使用完整轨迹的进展信息；在线输入只能使用当前及过去数据。整回合 min-max 归一化或未来是否恢复可以用于构造训练标签，不能在在线 gate 中偷看未来。本文核验范围内没有找到足以支撑“高频快速决策”的端到端延迟基准。

**创新边界：未来特征 + 价值趋势 + 记忆恢复已被覆盖。** 后续论文应证明更具体的表示增益、物理条件迁移或累计专家成本改善，而不是重新组合这三个名字。

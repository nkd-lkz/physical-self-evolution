Research Focus · 2026-09-19 · 实验证据更新 2026-09-22

Universal Physical Token
for Robot Self-Evolution

核心问题：能否从已有 action-generation head 读出一个紧凑表示，用 measured transition prediction 与有效 physics constraints 对其 grounding，并在在线阶段不重新训练 action model 的情况下适应变化的接触动力学？

当前重点已经从“先把 RLT 调收敛”转为“先把 Physical Token 研究问题定义清楚”。 现有 baseline 证据说明 online RLT 并不稳定，因此 Physical Token 不再绑定单一 learner。 当前优先回答三件事：① action-side token 到底表示什么；② 哪些 physics / measured consequence 监督是真正可部署、可迁移的；③ 如何证明它比 backbone、history-only、action-only 等更有决策价值。

01 · 当前科研主线

2026-09-19：暂停继续堆实验变量，先把 Physical Token 的定义、近邻论文、可落地方案与验证合同梳理清楚。

A · Define the Physical Token明确 token 是 action-side physical consequence state，而不是把任意 action token / proprio latent 改名。
B · Collision Audit精读 FLARE、Pri4R、AGRA、CometVLA、PAR、DyWA、RoboPack、MSDP 等最近邻，逐项排除撞车。
C · Three Candidate RoutesRepresentation-first / Physical Critic / WAM-compatible interface，分别给出最小实现和 No-Go 条件。
D · Grounding Contract严格区分 proposed vs executed action、command vs measured state、known physics vs learned residual physics。
E · Learner-Agnostic ValidationRLT、RECAP、V-GPS/Q-VGM 或 WAM 都可作为 downstream；先证明 representation 本身有额外物理与决策价值。

当前 Research Claim

Action-generation features may expose a compact, physically useful control interface.

要验证的是：在相同 history / proprio / capacity 下，action-side readout 是否比 backbone / history-only / action-only 更能编码真实 interaction consequence，并帮助后续决策。

当前创新边界

Compact token、future prediction、physics correction、multisensory latent、cross-head adapter 都已有强近邻。

因此创新不能只靠“加 token / 加 physics loss / 冻结大模型”；必须通过 matched ablation 证明 action-side physical representation 的独立价值。

02 · Physical Token at the Action Head

Action-head feature

F_t^head：最终动作投影之前的 causal / pre-output features。

核心假设：更靠近动作生成

Robot history

Recent measured state + actual/executed-action history；只使用部署时真实可得信息。

禁止 future leakage

Robot metadata

Morphology、joint/action convention、control metadata，通过轻量 adapter 对齐。

跨本体需要实测
统一接口：z_t = E_phi(A_m(F_t^head), h_t, r)，输出固定 K × d 连续 latent，供 small online learner 使用。在线适应阶段 Base model 与 action head 保持冻结。
Action model family第一版 readout 约定必须注意

Diffusion / FlowSelected sampling-step features固定 sampling-time convention；包含 noise/time context

关键对照：Action-head tap vs Backbone tap。Action head 是否真的保留更多 decision-relevant physical information，必须由实验回答。

03 · Physical Objectives

第一版目标：L_token = L_ro + λ_dyn L_dyn + λ_phys L_phys

L_ro · Readout

重建 fixed / stop-gradient action-head feature target，保留已有动作与任务信息。

不允许该 loss 反向修改 base action model。

L_dyn · Transition

D(z_t, u_t, r) → measured future physical state

u_t 对应 actual / executed action；target 来自真实测得的后续状态。

L_phys · Constraints

第一版优先 kinematic consistency 与 actuator feasibility。

Contact / friction / force / rigid-body terms 只有 sensing、model、calibration 有效时才加入。

第一版允许进入 L_phys 的内容
  • ||v_EE - J(q) q_dot||²，且所有量必须在同一 frame / unit / convention 下；
  • joint limit violation；
  • joint / actuator speed limit violation；
  • 其他明确存在、可审计的 controller / actuator constraints。

不是因为 simulator 能导出 mass / friction / impulse，就默认它们可以成为主实验里的“物理规律监督”。

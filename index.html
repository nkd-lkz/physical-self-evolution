Leadership-aligned Research Mainline · 2026-09-14

Universal Physical Token
for Robot Self-Evolution

核心问题：能否从已有 action-generation head 读出一个紧凑表示，用 measured transition prediction 与有效 physics constraints 对其 grounding，并在不重新训练 action model 的情况下适应变化的接触动力学？

当前研究不再以“泛化的 Physical Experience / World Model / 多阶段自进化框架”为实验主线。 第一组正式问题被严格收敛为：RL Token / matched head readout → + transition loss → + physics loss，所有比较在 matched token size、learner capacity、data 与 interaction budget 下完成。

打开领导版主规范

01 · 当前科研主线

目标是“轻量接口吸收物理变化”，而不是重新训练整个 action model。

A · Baseline / Extraction复现 RL Token，固定 action-head extraction contract，并做 backbone tap vs head tap。
B · Transition Grounding加入 actual/executed-action conditioned measured transition prediction。
C · Physics Grounding加入有效的 kinematic consistency 与 actuator feasibility。
D · Online Adaptation冻结 base/head/token，仅更新 small actor/critic，比较 adaptation cost 与 retention。
E · Universal Hypothesis当前模型/机器人上成立后，再做 held-out action-head family 与 held-out embodiment。

当前准确 Research Claim

Action-head compact readout can be physically grounded.

我们要验证的是：加入 measured transition 与有效 physics constraints 后，compact token 是否更适合在线适应，而不是笼统声称“模型学会了物理规律”。

Universal 的边界

Universal = shared token shape + shared objectives + lightweight adapters。

跨模型、跨本体目前都是 empirical hypothesis。没有 held-out tests 前，不写成结果。

02 · Physical Token at the Action Head

Action-head feature

F_t^head：最终动作投影之前的 causal / pre-output features。

核心假设：更靠近动作生成

Robot history

Recent measured state + actual/executed-action history；只使用部署时真实可得信息。

禁止 future leakage

Robot metadata

Morphology、joint/action convention、control metadata，通过轻量 adapter 对齐。

跨本体需要实测
统一接口：z_t = E_phi(A_m(F_t^head), h_t, r)，输出固定 K × d 连续 latent，供 small online learner 使用。Base model 与 action head 保持冻结。
Action model family第一版 readout 约定必须注意
Regression / MLPPenultimate activations与 final action projection 分开
Diffusion / FlowSelected sampling-step features固定 sampling-time convention；包含 noise/time context
AutoregressiveCausal states before logits不能读取 future demonstrated actions

关键对照：Action-head tap vs Backbone tap。Action head 是否真的保留更多 decision-relevant physical information，必须由实验回答。

03 · Physical Objectives

第一版目标：L_token = L_ro + λ_dyn L_dyn + λ_phys L_phys

L_ro · Readout

重建 fixed / stop-gradient action-head feature target，保留已有动作与任务信息。

该 loss 不允许反向修改 base action model。

L_dyn · Transition

D(z_t, u_t, r) → measured future physical state

其中 u_t 必须对应 actual / executed action；target 来自真实测得的后续状态。

L_phys · Constraints

第一版优先 kinematic consistency 与 actuator feasibility。

Contact / friction / force / rigid-body terms 只有 sensing、model、calibration 有效时才加入。

第一版允许进入 L_phys 的内容
  • ||v_EE - J(q) q_dot||²，且所有量必须在同一 frame / unit / convention 下；
  • joint limit violation；
  • joint / actuator speed limit violation；
  • 其他明确存在、可审计的 controller / actuator constraints。

不是因为 simulator 能导出 mass / friction / impulse，就默认它们可以成为主实验里的“物理规律监督”。

## 全文升级

### [AdaHVLA: Adaptive Harnesses for Long-Horizon Vision-Language-Action Execution](../papers/adahvla.md)

用机器人执行证据持续改写代码式 coordination policy；分析、修订与行为评估在分离上下文中进行，候选、假设和效应写入跨任务 revision graph。NaVILA-LH 测试从 Single VLA 2.5%、初始 harness 22.5% 提升至 31.7%–57.5%；VLA-Arena 三种 backbone、两种难度也均提高。量化主要为仿真，真机仅有定性轨迹；外层改写规则未自我修改。

### [Online Sim-to-Real Adaptation via Closed-Loop System Modeling](../papers/osram.md)

OSRAM 用少量真机 reference–response 数据微调闭环模型，再由 MPPI 改写参考命令，底层 PPO 策略冻结。LimX Tron1 硬件速度任务中 RMSE 从无适应的 0.2847 降至 0.2014；loco-manipulation 的 x 方向 RMSE 从 36.94±3.02 cm 降至 3.11±0.31 cm。每方法硬件重复只有 5 次，研究对象是低维控制接口适应，不是高层策略 RSI。

### [RAPID: Robot Agentic Programming from Demonstrations](../papers/rapid.md)

从单个视觉示范自动推断任务规格、对象关系和轨迹优化原语，并在重建仿真及场景变体中反复执行—验证—修订代码。8 个非抓取任务、每任务 50 个新仿真场景、3 次运行时，平均成功率由 CaP-Agent0 的 0.146±0.025 提升到 0.759±0.024；Franka 为 8×10 场景。程序在目标场景部署时固定，属于可验证程序构造，不是部署后持续改进。

### [AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control](../papers/ad-wm.md)

通过 residual latent transition、inverse recovery 与互信息式 action-recovery 目标，让世界模型保留候选动作差异。匹配 LeWM 的 Cube hard-start 成功率从 3.7±1.4% 到 52.0±3.1%；Franka 基础抓放从 19/45 到 32/45。部署不更新模型，人工提供图像子目标，应作为预测—行动支撑组件，而非持久 RSI。

## 近期旧稿补漏

### [An Analysis of Streaming Deep Reinforcement Learning for Adaptive Continual Learning in Robotics](../papers/streaming-deep-rl-continual-robotics.md)

预训练后以 batch size 1、只用最新 transition、无 replay 地持续更新 Stream-AC。四足三种突变的最佳峰值成功率为 0.968/0.848/0.676，显著高于预训练和 batch PPO；但 Push Cube 峰值 0.784、全程均值仅 0.233，之后回落约 20%。论文只测一次 M0→M1 的 forward transfer，未回测旧任务，不应作为抗遗忘证据。

## 失败与证据警戒

- 周末无新 arXiv 批次；这是列表状态，不代表其他平台没有新上传。
- OpenReview 论坛页触发浏览器验证，VLA-in-the-Loop 只进引文队列；没有根据二手博客补写。
- AdaHVLA 的 120 次测试评估不是 120 个独立任务；真机没有量化分母。RAPID 真机结果只在图中，卡片不从柱高再造精确总分。
- OSRAM 的跟踪误差只在成功试验上平均；AD-WM 真机为人工子目标和非随机模型块；Streaming RL 全部为 dense-reward 状态仿真。引用时必须连同这些条件。
- 五篇都没有实证外层改进器自身变强，未升级为严格递归 RSI。

## 最值得先读的三项

1. **[AdaHVLA](../papers/adahvla.md)：** 目前较完整的代码式 harness 持久改写、证据绑定、分支保留和留出测试协议。
2. **[Streaming Deep RL for Robotics](../papers/streaming-deep-rl-continual-robotics.md)：** 用峰值后衰退说明“学到过”与“持续保住”必须分开评价。
3. **[AD-WM](../papers/ad-wm.md)：** matched 对照表明最低事实预测误差不等于最佳闭环控制，是世界模型章节的重要反例。

## 对综述结构的直接影响

- 将代码/harness 更新再拆成：跨任务 revision graph、每任务离线程序构造、部署时冻结执行。

- 单列“模型—接口适应”：闭环模型可持久更新而策略冻结，不能与策略参数 RSI 合并计数。

# RLT 接触经验实验：先验证 loss，再验证记忆

**2026-09-24｜执行提案，未训练、未复现、无性能结果。** 延续仓库的 [09-22 物理经验合同](../../../research/physical-experience-protocol-2026-09-22.md)，不替换现有路线。当前优先完成数据合同和离线 probe；在线比较依赖可信 reference、learner 与干预闭环。这里的可运行代码仅是日志校验器，RLinf rollout adapter、特征导出和训练接入仍待实现。

## 1. 同事讨论时先讲清的一个问题

**固定大模型、历史输入和小型 RL learner 后，实际执行后果监督能否让紧凑表示更好预测接触响应，并减少达到同等任务能力所需的交互或专家控制时间？**

第一篇工作的候选贡献是“可测后果的表示与使用”，不是完整 RSI 系统。只有第一层通过，再问：这些响应能否压缩成可检索经验，帮助新的初态或物理条件？

近邻边界：Zeva-Ego 已有 action–effect 编码、视觉差分辅助目标和 action-expert 记忆注入。仅“加 effect loss + memory token”不够新；需要匹配输入/容量的对照，以及视觉差分 vs 实测响应、同实例重试 vs 新实例复用。完整论文创新性仍须扩展近邻核查。

## 2. 第一版 physical 的操作定义

先定义为 **给定部署历史与实际动作，机器人和对象出现的可测变化**。最小标签按可靠性递增，而非第一天写一套牛顿定律：

| 标签层 | 首选目标 | 如何取得 / 不能混淆什么 |
| :--- | :--- | :--- |
| 运动后果 | 实测关节变化、末端位移 | 从测得状态计算；控制器目标不等于实测状态 |
| 相互作用 | 对象相对末端的位移、抓持后是否跟随 | 仿真真值作标签；部署不可得时不输入模型 |
| 接触事件 | 建立/丢失接触、滑移、停滞 | 明确传感器、阈值与有效区间；缺失不是负例 |
| 任务后果 | 进展、失败、剩余预算内可恢复性 | 依赖任务与后续策略；不能统称为物理定律 |

力/冲量不可可靠读取时，第一版只做运动与相对运动。命令—响应偏差也可能来自限幅、延迟、不可达或估计误差，不能直接命名为摩擦/刚度。仿真参数改变一次只选一个：例如质量或摩擦的三档；范围先检查可达性和参考策略是否还有成功机会。

## 3. 损失和梯度究竟加在哪里

令 H_t 为截至决策时刻可得的历史；F_t 为冻结 VLA 的特征；z_t=f_φ(F_t,H_t) 为小型 readout。D_ψ 接收 z_t、执行命令前缀 u_exec 和实际时长 τ，预测未来实测标签 y。**未来观测只用于标签；绝不拼进 z_t。**

```math
\hat y_t=D_\psi(z_t,u^{exec}_{t:t+C_t-1},\tau_t),\qquad
L=L_{rec}+\lambda_m L_{motion}+\lambda_e L_{event}.
```

`L_motion` 用训练集尺度归一化后的 masked Huber；`L_event` 用有效事件的 BCE。各头按各自有效标量数归一化，某头全缺失时跳过而非填零。连续事件存在严重类不平衡时，在训练集定权重并同时报 PR-AUC/基率。运动以统一坐标计算，旋转用明确的 SO(3) 约定，不直接做欧拉角差。

- **离线：**冻结 VLA，更新 readout、重构头与后果 decoder；所有组共享离线数据和更新预算。原 RLT token 做基线；另以相同容量的 head readout 隔离提取位置。
- **在线首轮：**冻结 VLA、readout 和后果 decoder，只更新既有 actor/critic，保持奖励、BC、专家、gate 与 H/C 不变。actor 消费 grounded token；辅助 decoder 默认只评估，不凭空多加一项奖励。
- **后续 B2：**有效时增加预测关节与预测末端的 FK 一致性，如 `||FK(q_t+Δq_hat)−(p_t+Δp_hat)||`；统一参考系。只对测得真值计算一个常数 residual 不会训练表示。不得用全局动作平滑抹掉接触冲击。
- **时序边界：**u_exec 是实际发送并执行的命令序列，不是预测出的未来测量轨迹；τ 来自回执。在线事前排序只能给候选动作与计划时长，未来提前终止并不可知，不能直接拿事后 decoder 成绩声称已能规划。

AR / diffusion / flow 都可以做 readout，但这只是接口层可行性，不是跨架构结果。diffusion/flow 特征必须固定层、去噪时刻和采样随机性约定；禁止用未来专家动作 teacher forcing 生成测试输入。现有 prefix tap 与计划中的 action-head tap 分列，不能改名混用。

## 4. 分阶段矩阵：本周不用把所有组都跑一遍

| 阶段 | 要做什么 | 最小对照与预算起点 | 通过条件 / 停止条件 |
| :--- | :--- | :--- | :--- |
| E0 数据与基线 | reference 回放、BC-only、动作/时长/终止检查 | 先 4–8 个串行开发回合；成功和失败视频逐条对账 | 控制映射或时序不一致就先修；不启动长在线实验 |
| E1 离线筛选 | 缓存约 20–30 条成功/失败轨迹，先预测运动后果 | 零变化、state+history+action、prefix/RLT、同容量 head、head+后果 | 按 episode 划分；若不胜简单历史/静止预测，检查标签或停止扩张 |
| E2 loss-first | 可信 learner 上比较原表示与后果监督 | 单任务 3 个训练 seed 的筛选；先锁预算再跑 | 预测提升但控制不提升，只能支持表征信息，不称样本效率提升 |
| E3 记忆机制 | 冻结策略与表示，训练一个可读记忆的小 adapter 后再冻结 | 同容量无检索、随机合法记忆、相似视觉记忆、响应记忆 | 查询必须只读过去；真值检索只能作 oracle 上界 |
| E4 留存与迁移 | 重试、独立新实例、旧条件回测三种协议 | 相同尝试数、检索容量、数据来源和环境预算 | 只在同实例重试有效时，结论限定任务内适应 |

E1 的 20–30 条只筛信号，不是发表规模。可从固定 readout 宽度、两层小 MLP、AdamW `3e-4`、最多 2000 updates 开始做工程调通；这些是建议起点，不是已调优配方。正式训练量由开发集学习曲线决定并在测试前冻结。第一轮 λ_m 仅在 `{0.1,1}` 两点开发集筛选，λ_e=0；有效事件确认后才单独加入，避免一次搜索过多变量。

E2 必备归因对照（资源不足可分批，但论文不能省略其作用）：

| 组 | 固定公共历史、readout 输出维度与下游输入宽度后，改变什么 |
| :--- | :--- |
| B0-RLT | 原 prefix/RLT 表示与原重构目标 |
| B0-Head | head 特征与同容量 readout，只重构；隔离 tap 位置 |
| B1-Visual | 同 B0-Head，预测视觉特征差分；针对 Zeva-Ego 近邻思想的受控基线，不冒称复现整篇 |
| B1-Measured | 同 B0-Head，预测实测运动/交互后果 |
| B1-Future | 通用未来特征预测，分辨“有辅助预测就够” |
| B2-ValidPhysics | 仅在 B1 有效后，增加有适用条件的物理一致性 |

state/history-only、reference-only、expert-only，以及同纠正数据的 BC/DAgger 类对照亦需保留；离线 head 与 prefix 的导出成本单独计账。若更宽输入/更多参数产生收益，以同宽随机/非物理投影作容量控制。不要同时加入新恢复数据、学习 gate、奖励模型和记忆后全部归因于 loss。

## 5. 记忆库最小实现：先存结构化响应，不先造语言知识库

每条经验包含 `历史摘要 / 已执行命令 / 响应 / 阶段 / 有效性 / 控制者 / 结果 / 版本 / 数据来源`。区分两类库：**控制经验库**供策略查询；**研究实验库**供 Astra/harness 选下一组实验。两者不能混成一个“长期记忆”效果。

最小控制库：训练/适应轨迹 → 有效性检查 → 去重和按阶段分层 → 冻结 key/value 编码器 → 建立本地索引。key 来自当时可部署历史，value 编码已发生的动作—响应；容量先设 256 条、top-k=4、历史至多 4 个已完成 chunk，均在开发集调整。失败响应可入库；失败动作不自动作为正向模仿目标。

```math
m_t=\sum_{i\in TopK(q(H_t),k_i)} w_i v_i,\qquad
\tilde z_t=P([z_t;m_t]).
```

`P` 将拼接结果映射回原输入宽度；无记忆组使用相同结构和零 value。adapter 需在训练阶段见过可用记忆，不能把向量塞进从未训练过该接口的冻结 actor。支持集只能取训练 episode 中更早、不同实例的数据；mask 自身与未来片段，防止检索到自己的监督答案。

这证明的是“历史是否有决策价值”，不证明压缩后无信息损失。检索先异步预取并缓存，在阶段变化或异常后刷新；记录端到端 p50/p95 时延、超时率、吞吐和内存。超过预注册控制时限时使用已验证的无记忆分支；不可宣称加入 token 就必然更快。

## 6. 自进化的三种实验必须分开

| 协议 | 数据写入与重置 | 问题与指标 |
| :--- | :--- | :--- |
| A 同实例重试 | 每实例最多 4 次，每次恢复同一初态；BIT 清空，PIM 保留/清空成对比较；换实例清空 | 分别报告第 1/2/3/4 次成功率与总交互；累计“曾成功”另报，不能混用 |
| B 新实例复用 | 从独立适应支持集写库；冻结库后在新的初态/物理条件查询；策略权重不再更新 | 对比无库、视觉库、响应库；固定尝试数，测试结果不写回支持集 |
| C 顺序适应 A→B→A | B 阶段采集并写入；每阶段之后冻结资产，用新的独立 query 集评估 | 新条件收益、回到 A 的保持率、总数据/库大小/时延；适应支持集与 query 集分离 |

“B 新摩擦条件有效”仍不是“新任务有效”；跨任务实验必须按任务身份留出。测试参数 μ/mass 等只供分层评分，不参与部署检索。随机记忆来自同一合法候选池，控制阶段、容量和样本质量，避免拿明显无效片段做稻草人。配合记忆清空与合法历史交换，检查动作是否改变且是否朝正确方向改变。

## 7. 预算、指标与验收

正式 E2 前用 run card 锁定：实际控制步/机器人秒数、专家秒数、离线样本、learner updates、GPU/墙钟、训练 seed、选模规则、评测初态与频率。**不同策略的在线轨迹不可能完全一样；匹配的是预算和分布。** 折扣按原算法的真实执行间隔审计，不能把早停 chunk 当成满长 chunk。

首要论文指标沿用既有合同：在预注册无专家成功率目标及吞吐要求下，达到目标所需的累计专家控制时间；同时报告固定预算成功率与成功率—交互曲线。没有干预闭环时先报预测与固定预算成功率，不能制造“减少人工”结论。预算内未达标单列，不能用最后一个 checkpoint 冒充达标。

离线报告 motion NMAE、事件 PR-AUC/基率、Brier/校准和不同物理条件的误差；在线报告无专家/允许专家两种成功率、专家时长、切换次数、物理失败率与端到端延迟。成功由独立环境条件判定，decoder/Q/LLM 自评都不是地面真值。

开发筛选可用每 checkpoint 20 个固定初态；扩展验证建议至少两个任务、每组 3 个训练 seed、每 seed 50 个独立评测 episode 起步，之后按目标效应与方差确定样本量。该建议不保证统计功效。按训练运行统计方差，配对初态比较；相邻帧和同实例重试不能冒充独立样本。

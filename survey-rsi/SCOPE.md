# 公开文献范围与来源边界

本目录是可独立阅读的具身 / 机器人 RSI 综述文献库。

| 可以收录 | 需要满足的条件 |
| :--- | :--- |
| 论文、作者项目与代码 | 回到原始来源，记录版本、日期和证据定位 |
| 企业原文、研究者公开观点 | 有可访问完整出处；观点和独立实证分开 |
| 整理者的综述分析 | 基于已列公开来源，说明哪些是综合判断、哪些是原文结论 |
| 分类轴、比较表、写作提纲 | 服务跨文献组织，不引入其他项目的方案或进度 |

## 内容和读取边界

- 综述任务只读取本目录、必要的 Git 元数据与公开原始文献；仓库其他项目内容不作为输入。
- 不收录项目研究随想、未发表方法、代码设计、实验方案、项目指标或私聊上下文。不能通过改写成“综述启发”将这些内容带入。
- 不在正文、图片、数据、索引、历史日志或链接中回指其他项目区。其他项目可单向引用这里的公开文献；它们的应用推论留在各自项目中。
- 同名方法或缩写需区分公开论文与本地项目；公开发表的论文仍可正常收录，以原论文为来源。
- 媒体材料没有完整公开出处时只保留待核实状态，不据标题和截图重建其观点。

## 维护与检查

运行 `python survey-rsi/scripts/check_boundary.py` 检查本地链接、项目路径和已知混入标记；再核对内容来源。自动检查只能发现已定义的结构问题，不能代替语义审查。

平时保留历史日志。发现跨区内容时，只有用户明确授权清理后才进行范围更正，并保留文献日期、计数与更正说明；不得在更正日志中再次复述被移除的项目内容。不能以“保留历史”为由在综述区继续展示这些内容。

此规则限制内容流向，不改变公开仓库的访问权限，也不抹除 Git 历史。

# RegenHarness: A Robot Agent Harness with Evidence-Gated Recursive Self-Improvement

> **一句话：** 提出可追溯 harness 修订协议；现有真机案例未证明递归收益。

## 解决什么问题

 高层模型认为任务完成、控制器返回完成和物理任务真的完成，并不是同一件事。长程机器人执行还需防止重复派发、过期证据与无限恢复。

## 核心方法

 将计划、监督、验证、恢复隔离为四类上下文；记忆区分观测事实和已验收事实，只有绑定任务身份和版本的证据能提交进展。资源租约、去重与持久恢复预算约束执行。作者另提出跨任务 RSI 协议：依据执行记录提议修改上下文规则、模板、路由和恢复配置，经固定回归检查、发布授权、版本化上线及回滚后保留。基础模型不在线更新，验收门控不允许被削弱。

## 主要结果

 证据为四足机器人的语音触发仓库巡检、全景观察、分析、报告及返回等集成案例。主要外出和返回路径各 17.62 m，独立环路案例 18.83 m；记录到达残差 0.11/0.17/0.25 m，容差 0.4 m。这些来自系统自身定位记录，不能写成外部动捕测得的精度。论文没有给出多轮 harness 修订前后的成功率、预算相等对照或统计显著性结果；§6.8 是比较评测方案。

## 综述可借鉴之处

 可放入“改进发布与证据验收”的系统设计章节：版本绑定、候选修订、冻结回归标准和回滚是值得纳入综述的工程维度。它延续已在候选池中的 HROS；关系已由正文确认，但两者不是同一 arXiv 条目的版本。

## 证据边界

 **标题含 Recursive Self-Improvement，不代表已证明递归自我增强。** 当前实证主要支持执行链集成，尚未验证配置演化带来收益，更没有证据表明提议器/学习规则被增强。角色隔离也不等于验证器独立可靠；后台取消、停止确认等契约有适用假设。综述应引用其协议设计，并明确把能力增长主张列为待验证。

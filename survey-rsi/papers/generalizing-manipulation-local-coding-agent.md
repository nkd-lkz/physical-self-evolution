# Generalizing Manipulation Skills with a Local Coding Agent

短名：Local Coding Agent　作者：Raman Talwar, Elias Nijs, Andreas Verleysen, Francis Wyffels　首次发表：2026-09-22　采用版本：arXiv v1　发表状态：预印本

**解决什么问题：** 通用编码代理能否仅凭本地模型、少量机器人技能文档和可执行工具，在未为每项任务预写控制程序的情况下完成真机操作，并在同一任务实例的再次尝试中复用自己的执行经验。

**核心方法：** 作者在单工作站运行Qwen3.8-27B与pi编码harness，把UR3e的运动、视觉、力/接触、运动学和安全能力封装成九个HTTP操作，并提供六份人工编写的技能文档。代理在隔离工作区中编写、运行和修改代码。每项新任务都从空工作区开始；“再次尝试”则恢复同一会话中的测量、代码和计划，不更新模型权重，也不形成跨任务共享技能库。

**主要结果：** 九项任务各5次，共45次真机试验，30次无需操作员干预成功；单次耗时3.4–67.5分钟。对重排场景恢复原会话的17组配对试验中，16/17无需干预，工具调用354对734、耗时比0.48、输出token比0.34，推理占比由80%降到67%；但仍有个别二次尝试更慢或失败。结果支持“保存可执行工件能降低后续成本”，尚不能证明能力本身跨任务持续增强。

**综述可借鉴之处：** 可放在“技能/代码/harness演化”章节，作为改进对象从权重扩展到代码工件的真机案例；也提示评价应分别报告成功率、交互成本、时间和复用范围。与LEMCA相比，它有真机执行但没有跨任务架构搜索；与DROC一类持久知识库相比，其复用被限制在同一会话。

**证据边界：** 任务是九项小型桌面玩具任务；没有学习基线、跨任务保留或模型参数更新。技能文档、工具接口和安全机制均由人预先设计；作者称的experience reuse主要是同一任务会话内重用，不应直接归为持久RSI，更不涉及改进器递归增强。

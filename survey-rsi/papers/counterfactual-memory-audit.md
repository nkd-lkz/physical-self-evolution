# Memory That Changes Action Is Not Memory That Guides It: Counterfactual Auditing of History-Conditioned Robot Policies

> **一句话：** 证明“动作因记忆变化”仍不足以说明机器人用对了记忆。

## 解决什么问题

 有记忆模块、动作受历史影响、任务最终成功，三者都不能单独证明记忆提供了正确的行动依据。现有成功率可能掩盖“记住了但选错分支”的错误。

## 核心方法

 Counterfactual Memory Audit（CMA）构造两段合法历史，使当前图像、状态和指令相同，但正确行动应不同。冻结策略、配对随机性，交叉置换历史/记忆，再在匹配物理状态中执行已保存动作，分别测动作敏感性、语义选择、物理价值和成对可靠性；另做原生轨迹记忆清空、替换及保护锚点恢复实验。

## 主要结果

 Mem-0 的 Put Back **64 对**审计情境全部发生动作变化，但只有 **20/64 对**在所有方向和种子下可靠；later Swap 的 24 对动作都变化，却没有改变任务分支。在独立 36-episode 故障队列中，恢复 4096 字节锚点使成功由 **6/36→20/36**，提高 38.9 个百分点，仍低于未扰动的 26/36。PiPER 真机每任务 **8 对／32 次执行**：Put Back 完成操作 9/32，其中 5/9 操作了错误目标，完整成功只有 4/32。不能只报“完成 9 次”。

## 综述可借鉴之处

 适合放进“记忆改进到底改善什么”和“评价独立性”章节，与 MessyMem、2AM、Zeva-Ego 对照。建议把持久保存、实际检索、正确影响决策和跨任务收益分别列为证据要求。

## 证据边界

 这里主要研究任务内历史依赖，并非学习出新策略或证明跨部署自我改进。38.9 点来自人为注入记忆故障后的恢复，不能解释为正常运行中的能力增长。真机独立单位是 8 对情境，32 次不是 32 个独立任务；标签由操作者提供、非独立盲评。自然轨迹中的错误与最终失败关系为观察关联。

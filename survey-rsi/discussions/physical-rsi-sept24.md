# 三条新线索与 GLOW 补充：什么能进入 RLT 实验？

**2026-09-24，研究分析与实验提案，未运行机器人实验。** 本次正文线索为 Simate、Skild、Zeva / Zeva-Ego，另一个附件实际讨论 GLOW，因此共处理四条技术线索。Zeva-Ego 已有卡片，只作修订。它们不共同组成一个已经成立的“首个 Physical RSI”。

## 四种更新对象

| 线索 | 主要变化 | 反馈与保留范围 | 对我们的直接价值 | 不宜据此宣称 |
| :--- | :--- | :--- | :--- | :--- |
| [Simate](../cases/simate-autoresearch.md) | 研究方案、配置和实验流程 | 评测与研究记录，公开完整迭代归因待补 | 版本化研究记忆、预算与接纳规则 | 榜首已证明改进器递归增强 |
| [Skild](../cases/skild-physical-self-play.md) | 策略参数与近期对手 | 仿真进球回报与对抗课程 | 有验证目标的采样难度调整 | 真机在线持续学习、普适无奖励 |
| [Zeva-Ego](../papers/zeva-ego.md) | 冻结参数下的 BIT/PIM 上下文 | 同任务实例跨尝试；新实例清空 PIM | 动作—响应、记忆注入与重置对照 | 已有跨任务终身记忆 |
| [GLOW](../cases/knowin-glow.md) | 执行回执与上下文，经验生成/训练链路 | 自身执行记录；递归收益仍需逐轮证据 | 实测后果标签与执行不匹配诊断 | 子集排名等于官方总榜、步数等于时延 |

这些区别提供的是**研究维度**，不是由弱到强的统一官方分级。人的参与程度、保留跨度、更新对象与物理证据应分别标注。

## 最新近邻改变了什么

Zeva-Ego 已经包含动作效果监督、双时间尺度记忆与动作端条件注入。因此，“加后果 loss + memory + token”不能作为充分创新描述。其 v2 附录的 effect 目标是自监督视觉差分；PIM 是同一实例的尝试记忆。我们的候选问题应进一步收紧为：

> 在匹配历史、表征维度、模型容量与交互预算后，**实测接触响应监督**是否比视觉差分监督更有助于小型在线 learner？以这种响应组织的经验，能否帮助**新的初态或物理条件**，而不只是同一实例多试几次？

这仍是待证的差异，不是新颖性结论。RLT、UniIntervene、Zeva 系列及库中的记忆审计都需要作为近邻回查。称作因果经验时，还要说明实际干预或识别条件；普通动作—后果相关性本身不能证明因果辨识。

## 当前选择：先做什么，暂时保留什么

| 顺序 | 具体工作 | 与既有主线的关系 |
| :--- | :--- | :--- |
| 现在 | 修复 reference / BC / 时序，增加动作回执记录，离线后果 probe | 延续 loss-first，不更换在线算法 |
| 门槛通过后 | B0 重构、B1 实测后果、通用 future 与视觉差分对照 | 分离监督与输入/容量收益 |
| 再下一步 | 静态响应库、同实例重试、新实例只读复用 | 记忆作为扩展，保留清空/错配对照 |
| 后续独立分支 | 学习进展课程、注意力 selector、Jev 局部选择、参数 TTA | 一次只增加一个新变量 |
| 研究基础设施 | Astra 提议失败假设，harness 记录版本、预算、评测与回退 | 可提高研发效率，不自动成为控制方法贡献 |

## 三个特别容易误读的数字

1. Simate 33.95 是 Score，27.96% 是成功率；它们来自官方仿真榜快照。
2. GLOW 62.2% 来自作者报告的 18 个仿真任务子集；不能据此宣布它高于或低于完整总榜方法。
3. Zeva-Ego 的 58%→89% 是跨尝试报告。v2 的 §5.4.1/Fig.11 与结论中的 sim/real 措辞存在归属不一致，卡片单列此问题；不能把它写成独立新任务上的长期成长。

## 从“有闭环”到“改进器更强”还差什么

建议依次验证：真实反馈进入更新；更新能持久保留；保留资产帮助后续独立运行；收益超过同预算固定资产对照；旧能力可保持。若进一步研究 RSI，则应额外冻结任务执行器，单独比较新旧改进器在新开发问题上的成功修复数/预算。由同一研究 Agent 反复调参，但 Agent 与选择规则没有被修改，不足以证明后一层递归。
